# 기능 정의서

## 1. 권한 구분

DOHA Deck은 다중 사용자 플랫폼이 아니라 관리자 1명이 프로젝트를 관리하고, 방문자는 공개된 프로젝트를 열람하는 개인 프로젝트 아카이브 CMS다.

### 1-1. 방문자

방문자는 별도 로그인 없이 공개 프로젝트만 조회할 수 있다.

- 공개 프로젝트 목록 조회
- 공개 프로젝트 상세 조회
- 발표 모드 조회
- 기술스택 기반 필터
- 프로젝트 검색
- GitHub 링크 이동
- 배포 링크 이동
- 발표자료 링크 이동
- README 링크 이동

### 1-2. 관리자

관리자는 로그인 후 프로젝트 데이터를 등록, 수정, 삭제할 수 있다.

- 관리자 로그인
- 관리자 대시보드 조회
- 프로젝트 등록
- 프로젝트 수정
- 프로젝트 삭제
- 공개/비공개 설정
- 기술스택 관리
- GitHub 링크 관리
- 배포 링크 관리
- 발표자료 링크 관리
- README 링크 관리
- 주요 기능 작성
- 아키텍처 작성
- 트러블슈팅 작성
- 회고 작성

## 3. API 기능

### 3-1. 인증

- `GET /api/auth`: 관리자 세션 확인
- `POST /api/auth`: 관리자 로그인
- `DELETE /api/auth`: 로그아웃

### 3-2. 프로젝트

- `GET /api/projects`: 공개 프로젝트 목록 조회
- `GET /api/projects?includePrivate=1`: 관리자 전체 프로젝트 목록 조회
- `POST /api/projects`: 프로젝트 등록
- `GET /api/projects/[projectId]`: 프로젝트 상세 조회
- `PATCH /api/projects/[projectId]`: 프로젝트 수정
- `DELETE /api/projects/[projectId]`: 프로젝트 삭제

`projectId`는 DB `id` 또는 `slug` 모두 사용할 수 있다.

### 3-3. 파일

- `POST /api/files`: 관리자 등록/수정 화면에서 파일 메타데이터 확인

현재 파일 API는 실제 영구 저장이 아니라 미리보기/검증 목적이다.

## 4. 고도화 기능

MVP 완성 이후 프로젝트의 완성도와 포트폴리오 가치를 높이기 위해 추가한다.

### 4-1. 파일 업로드 기능

현재 MVP에서는 발표자료와 README를 URL로 관리한다. 고도화 단계에서는 파일을 직접 업로드할 수 있도록 확장한다.

- 프로젝트 썸네일 이미지 업로드
- 발표자료 PDF 업로드
- 발표자료 PPT 업로드
- README 파일 업로드
- 이미지 파일 업로드
- Supabase Storage 연동
- DB에는 파일 URL 저장
- 파일명 표시
- 파일 크기 표시
- 파일 다운로드 링크 제공
- 파일 삭제 기능
- 프로젝트별 파일 목록 관리

### 4-2. README 자동 생성

프로젝트 등록 정보를 기반으로 GitHub README 초안을 자동 생성한다.

입력 데이터:

- 프로젝트명
- 프로젝트 소개
- 기술스택
- 주요 기능
- 실행 방법
- 배포 링크
- GitHub 링크
- 트러블슈팅
- 회고

출력 결과:

- README.md 형식의 Markdown 문서
- 복사 기능
- 다운로드 기능
- 관리자 화면에서 수정 가능

### 4-3. AI 발표 대본 생성

프로젝트 정보를 기반으로 발표용 대본을 생성한다.

생성 유형:

- 30초 소개 대본
- 1분 발표 대본
- 3분 발표 대본
- 면접용 프로젝트 설명
- 트러블슈팅 기반 면접 답변

사용 목적:

- 포트폴리오 발표 준비
- 면접 답변 준비
- 프로젝트 설명 문장 정리

### 4-4. 프로젝트 회고 템플릿

프로젝트 회고를 일정한 구조로 작성할 수 있도록 템플릿을 제공한다.

회고 항목:

- 프로젝트를 만든 이유
- 주요 구현 기능
- 어려웠던 점
- 해결 방법
- 기술적으로 배운 점
- 다음에 개선할 점

### 4-5. 트러블슈팅 관리 기능

프로젝트별 트러블슈팅 기록을 별도 구조로 관리한다.

트러블슈팅 항목:

- 문제 상황
- 발생 원인
- 해결 과정
- 적용한 코드 또는 설정
- 결과
- 참고 링크

고도화 방향:

- 트러블슈팅 태그 관리
- 면접 답변용 요약 생성
- 프로젝트 상세 페이지의 별도 섹션 표시

### 4-6. 기술스택 필터 고도화

방문자가 프로젝트를 기술스택 기준으로 더 쉽게 탐색할 수 있도록 개선한다.

- 기술스택별 필터
- Frontend/Backend/DB/Deploy/AI 분류
- 복수 기술스택 선택
- 검색어와 필터 조합
- 프로젝트 개수 표시

### 4-7. 프로젝트 통계 대시보드

관리자 대시보드에서 프로젝트 현황을 시각적으로 확인한다.

- 전체 프로젝트 수
- 공개 프로젝트 수
- 비공개 프로젝트 수
- 기술스택별 프로젝트 수
- 최근 수정 프로젝트
- 등록된 링크 수
- 등록된 파일 수

### 4-8. 공개 프로젝트 상세 페이지 개선

방문자에게 보이는 프로젝트 상세 페이지를 포트폴리오답게 개선한다.

- 프로젝트 대표 이미지 표시
- 주요 기능 카드 표시
- 기술스택 그룹 표시
- 배포 링크 강조
- GitHub 링크 강조
- 발표자료 보기 버튼
- 관련 프로젝트 추천

### 4-9. Slug 기반 URL

프로젝트 상세 URL은 숫자 ID가 아니라 사람이 읽기 좋은 slug를 사용한다.

예:

```txt
/projects/doha-deck
/projects/staccato
```

현재 구현에서는 프로젝트 등록 시 제목 기반 slug를 자동 생성한다.

### 4-10. SEO 설정

공개 프로젝트 페이지가 검색엔진과 공유 링크에서 잘 보이도록 SEO 정보를 설정한다.

- 프로젝트별 title 설정
- 프로젝트별 description 설정
- Open Graph 이미지 설정
- 공유 미리보기 설정
- sitemap.xml 생성
- robots.txt 설정
- 프로젝트 slug 기반 canonical URL 설정

### 4-11. 관리자 미리보기 기능

관리자는 비공개 프로젝트도 공개 페이지 형태로 미리 확인할 수 있다.

- 비공개 프로젝트 상세 미리보기
- 비공개 프로젝트 발표 모드 미리보기
- 방문자에게는 비공개 프로젝트 노출 불가
- 관리자 로그인 상태에서만 접근 가능

### 4-12. 프로젝트 데이터 내보내기

관리자가 프로젝트 데이터를 백업하거나 외부에 활용할 수 있도록 내보내기 기능을 제공한다.

- 프로젝트 단건 JSON 내보내기
- 전체 프로젝트 JSON 내보내기
- README.md 다운로드
- 발표자료 링크 목록 내보내기
- 트러블슈팅 기록 내보내기
