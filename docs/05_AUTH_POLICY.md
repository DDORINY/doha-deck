# 인증 및 권한 정책

## 1. 기본 정책

DOHA Deck은 다중 사용자 플랫폼이 아니라 개인 포트폴리오 CMS다.

일반 사용자 회원가입, 일반 사용자 로그인, 사용자별 권한 관리는 제공하지 않는다.

## 2. 방문자 권한

방문자는 다음 화면에 접근할 수 있다.

- 메인 페이지
- 공개 프로젝트 목록
- 공개 프로젝트 상세
- 공개 프로젝트 발표 모드

방문자는 `visibility = PUBLIC` 프로젝트만 볼 수 있다.

## 3. 관리자 권한

관리자는 다음 기능을 사용할 수 있다.

- 관리자 로그인
- 관리자 대시보드 조회
- 공개/비공개 프로젝트 전체 조회
- 프로젝트 등록
- 프로젝트 수정
- 프로젝트 삭제
- 공개/비공개 상태 변경

관리자 화면은 `/admin/*` 경로에 배치한다.

## 4. 세션 처리

관리자 로그인 성공 시 `doha_admin_session` 쿠키를 발급한다.

쿠키 설정:

- `httpOnly: true`
- `sameSite: lax`
- production 환경에서는 `secure: true`
- 만료 시간: 7일

세션 토큰은 HMAC SHA-256 기반 JWT 형식으로 서명한다.

서명 키 우선순위:

1. `JWT_SECRET`
2. `NEXTAUTH_SECRET`
3. `ADMIN_PASSWORD`
4. 개발용 fallback 문자열

운영 환경에서는 반드시 `JWT_SECRET`을 별도로 설정한다.

## 5. 관리자 표시 정책

공개 페이지 헤더는 로그인 상태에 따라 다르게 표시한다.

- 로그인 전: `관리자 로그인`
- 로그인 후: 관리자 이름 표시

관리자 이름을 클릭하면 관리자 대시보드로 이동한다.

## 6. 보안 주의사항

- `.env`, `.env.local`은 Git에 커밋하지 않는다.
- 관리자 비밀번호는 DB에 bcrypt hash로만 저장한다.
- 프로젝트 등록/수정/삭제 API는 반드시 관리자 세션을 확인한다.
- 비공개 프로젝트 상세 조회도 관리자 세션이 있을 때만 허용한다.
